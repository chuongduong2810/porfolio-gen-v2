## CV Builder

- Next.js App Router + TypeScript
- TailwindCSS with dark mode
- Zustand for state
- dnd-kit for drag-and-drop
- TipTap for rich text
- @react-pdf/renderer for PDF export

### Scripts

- `npm run dev`
- `npm run build`
- `npm start`
